# Identidad visual de CubPay

Actualización exclusivamente visual: verde tinta, marfil y oliva; Manrope para datos e interfaz e Instrument Serif para títulos editoriales. Marca SVG de dos rutas conectadas, iconografía lineal, navegación oscura y métricas agrupadas. Las fuentes se sirven localmente con licencia OFL incluida.

Referencias consultadas mediante el MCP de 21st (get_inspiration):

- Dashboard Sidebar: https://21st.dev/@arunjdass/components/dashboard-sidebar
- Financial Score Cards: https://21st.dev/@designali-in/components/financial-score-cards

Se consultaron metadatos como inspiración de composición; no se descargó ni reutilizó código de componentes de pago. La implementación visual es propia y no añade dependencias de ejecución.

No se modificaron cálculos, permisos, autenticación, endpoints, almacenamiento ni eventos de las acciones. La tabla conserva su desplazamiento horizontal dentro de su contenedor; su etiqueta accesible ya no expande el documento móvil. Se respeta la preferencia de movimiento reducido.
