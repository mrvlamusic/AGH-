# CubPay

CubPay is an invite-only B2B liquidity and settlement coordination platform for verified businesses.

> **Simulation-only MVP.** This repository does not move real money and does not connect to real banking, money-transmission, Cuba cash, or settlement rails.

## MVP scope
- Invite-only business onboarding
- KYB/compliance workflow
- Two-sided USD order book
- Partial matching
- 3–5% configurable service fees
- Double-entry ledger model
- Daily settlement batches
- Reconciliation
- Admin/compliance console
- Mock Cuba and U.S. provider adapters

See `AGENTS.md` and `docs/ARCHITECTURE.md`.
